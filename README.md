## 一、專案介紹（Project Overview）

Career Compass 是一個結合職涯探索、職缺搜尋、職能分析及工作比較的智慧求職網站，主要聚焦於產品經理（Product Manager, PM）與專案經理（Project Manager, PjM）兩大職涯領域。

隨著企業對於專案管理、產品開發、跨部門協作及數位轉型人才的需求日益多元，求職者需要具備更多元的專業能力。然而，許多大學生、社會新鮮人與轉職者在求職過程中，經常面臨以下問題：

1. 不清楚產品經理與專案經理的工作差異。
2. 難以從大量職缺資訊中找到適合自己的工作。
3. 不容易理解企業職務描述中要求的專業能力。
4. 缺乏有效工具評估自己的職能優勢及不足。
5. 求職資訊分散，難以進行職缺比較及長期追蹤。
